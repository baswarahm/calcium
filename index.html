      Help & Reference

      Basic operations

      Type expressions directly: 2 + 3 × 4 respects standard order of operations. Use ( ) to group, % button for percentage, ± to flip sign.

      Scientific functions

      Trig functions respect the active angle mode shown in the top bar (DEG / RAD / GRAD). Example: sin(30) in DEG mode returns 0.5.

      Variables

      Type x = 10 and press Enter to store a variable, then use x inside later expressions, e.g. x² + 5. Manage variables from the Variables tab.

      Matrix operations

      Open the Matrix tab, choose a size, fill in Matrix A (and B where needed), then pick an operation such as determinant, inverse, or multiply.

      Statistics

      Enter a dataset separated by commas or spaces, choose population or sample statistics, then calculate to see mean, median, mode, standard deviation, quartiles and more.

      Graphing

      Enter one or more functions of x (e.g. sin(x), x^2). Drag the canvas to pan, use the + / − controls or your scroll wheel to zoom, and "Reset view" to return to the default window. Graphing always uses radians.

      Equation solver

      Enter coefficients for a·x + b = c (linear) or a·x² + b·x + c = 0 (quadratic) to see the solution, including the discriminant for quadratics.
